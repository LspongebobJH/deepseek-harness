## Purpose and Scope

This page covers the core event-sourced session system (`@deepseek-ai/dsh-session`), its projection and derived message pipeline (`@deepseek-ai/dsh-session/surface`), session forking and lineage management, persistence backends (`@deepseek-ai/dsh-session-persistence-jsonl`, `@deepseek-ai/dsh-session-query-sqlite`), runtime state projections (`@deepseek-ai/dsh-session-projection`), and cross-session search and tracing (`@deepseek-ai/dsh-session-query`). It explains how model-visible histories are reconstructed from append-only logs and persisted across runs.

## Session Event Log

A `Session` manages a sequence of immutable events [packages/core/session/src/index.ts1-7](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/index.ts#L1-L7) Each event in the log is a `SessionEvent`, which wraps a type-specific payload in a standard envelope containing a monotonic sequence number (`seq`) and a Unix epoch timestamp (`time`) [packages/core/session/src/types.ts58-79](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L58-L79) Current logs stamp `SESSION_FORMAT_VERSION` at version `3` [packages/core/session/src/types.ts88-89](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L88-L89)

### Event Envelope Structure

The envelope is a discriminated union over the `type` field, allowing the TypeScript compiler to narrow the `data` payload [packages/core/session/src/types.ts58-79](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L58-L79)

| Field | Type | Description |
| --- | --- | --- |
| `type` | `SessionEventType` | The unique key for the event type (e.g., `user/message`, `turn/start`). |
| `seq` | `SessionSeq` | Monotonic sequence number within the session [packages/core/session/src/types.ts29-41](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L29-L41) |
| `time` | `number` | Unix epoch milliseconds [packages/core/session/src/types.ts64-65](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L64-L65) |
| `data` | `SessionEventMap[K]` | The actual payload for this event type [packages/core/session/src/types.ts66](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L66-L66) |
| `sourceEventSeqs` | `SessionSeq[]?` | Seq numbers of earlier events that this event cites as sources. Only on `SurfaceEventType` [packages/core/session/src/types.ts78-87](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L78-L87) |
| `surfaceOp` | `SurfaceOp?` | Metadata for events that appear on the LLM-visible surface (append or replace) [packages/core/session/src/types.ts42-45](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L42-L45) |
| `ignorable` | `true?` | If true, a reader can safely skip this event if the type is unrecognized [packages/core/session/src/types.ts87-89](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L87-L89) |

## Surface Projection & `deriveMessages()`

The **Surface** is an ordered projection of events that produce LLM messages (currently `system/message`, `user/message`, `assistant/message`, and `tool/result`) [packages/core/session/src/surface.ts22-26](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/surface.ts#L22-L26) While the log is strictly append-only, the Surface supports **positional replacements** to allow for history compaction and refinement [packages/core/session/src/types.ts30-45](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L30-L45)

### `deriveMessages()`

This function iterates over the `nodes` (sequence numbers) currently in the Surface and converts each corresponding event into a `Message` object for the LLM via `deriveEventMessage()` [packages/core/session/src/index.ts42-47](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/index.ts#L42-L47) [packages/core/session/src/surface.ts90-126](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/surface.ts#L90-L126)

- **Injected Context:** `user/message` events from plugins are projected as standard user roles, preserving the exact identified content [packages/core/session/src/surface.ts103-105](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/surface.ts#L103-L105)
- **Assistant Chunks:** Individual assistant attempt chunks are log-only; only the final `assistant/message` is projected to the surface if non-empty [packages/core/session/src/surface.ts113-117](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/surface.ts#L113-L117)
- **Compaction & Replacement:** When a `SurfaceOp` of type `replace` is used, the `SurfaceManager` shadows a range of prior surface nodes [packages/core/session/src/types.ts35-41](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L35-L41)

## Session Forking & Lineage

The `SessionStore` (accessible via `ctx.sessions`) manages the lifecycle of sessions, including creating new ones and forking existing ones [packages/core/session/src/index.ts33-37](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/index.ts#L33-L37)

### Forking Mechanics

`ctx.sessions.fork(source, boundary?, childSessionId?)` creates a new session that inherits a prefix of events from a parent session [packages/core/session/README.md58-60](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/README.md?plain=1#L58-L60)

- **Boundary:** An inclusive `SessionSeq` defining where the parent's history ends for the child.
- **Lineage Metadata:** The new session's `SessionHeader` records the `parentSession` ID and `isSeeded` status [packages/core/session/src/types.ts91-128](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/types.ts#L91-L128)
- **Inherited Prefix:** `Session.inheritedEventCount` retains the exact prefix length from the fork [packages/core/session/README.md62-63](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/README.md?plain=1#L62-L63)

## Persistence Backends & Projections

Persistence is implemented as a plugin concern. Plugins subscribe to the `session/event` Cordis event to receive live updates and `session/flush` to ensure durability checkpoints [packages/core/session/src/index.ts39-83](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/session/src/index.ts#L39-L83)

### JSONL Backend (`session-persistence-jsonl`)

The JSONL backend stores headers and contiguous events in immutable generation files [packages/session/session-persistence-jsonl/src/storage.ts](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/session/session-persistence-jsonl/src/storage.ts) (referenced via [packages/session/session-persistence-jsonl/tests/jsonl.spec.ts1-24](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/session/session-persistence-jsonl/tests/jsonl.spec.ts#L1-L24)).

- **Compression:** Supports checksummed Zstandard frames (`zstd`) or plain JSONL (`none`).
- **Format Versions:** Stamps `SESSION_FORMAT_VERSION` (`3`) into headers.
- **Atomic Writes:** Uses generation files and rename operations to guarantee atomic updates.

### SQLite Backend (`session-query-sqlite`)

The SQLite backend provides a derived index for full-text search (FTS5) and query capabilities over the session corpus [packages/session-query/session-query-sqlite/src/index.ts](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/session-query/session-query-sqlite/src/index.ts)

- **Search Database:** Opens a SQLite database using `node:sqlite` (`DatabaseSync`) [packages/session-query/session-query-sqlite/tests/sqlite.spec.ts4-5](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/session-query/session-query-sqlite/tests/sqlite.spec.ts#L4-L5)
- **FTS5 Indexing:** Extracts text from `user/message`, `assistant/message`, and `tool/result` payloads to populate search indices.

### Session Projections (`dsh-session-projection`)

The projection registry (`ctx.sessionProjections`) drives state-driven computation units forward over committed session events [packages/session/session-projection/src/index.ts1-47](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/session/session-projection/src/index.ts#L1-L47) Each `ProjectionDefinition` defines a pure synchronous `apply` fold, an `init` state creator, and an optional `wire` view for clients.
