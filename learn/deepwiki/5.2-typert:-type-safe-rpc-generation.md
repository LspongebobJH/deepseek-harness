Typert is the type-safe Remote Procedure Call (RPC) generation system within DeepSeek Harness (`dsh`) that enables seamless, type-safe interaction between the Node.js Host environment and the browser Client runtime [docs/api-gateway.md1-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L1-L16) [.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md1-26](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md?plain=1#L1-L26). It automates the transformation of decorated Host service classes into remote callable contracts and client proxies, ensuring compile-time type safety without manual proxy boilerplate [docs/api-gateway.md7-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L7-L16).

## 5.2.1 Purpose and Scope

Typert bridges the API surface of Host Cordis services to the browser Client transparently and type-safely [docs/api-gateway.md5-15](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L5-L15). Instead of importing Host code into the Client, Typert generates a set of platform-neutral contracts describing remote callable APIs with analyzed argument and return types [docs/api-gateway.md7-15](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L7-L15) [.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md14-25](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md?plain=1#L14-L25).

This separation ensures:

- **Strong type safety** between Host implementations and Client usage [docs/api-gateway.md10-15](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L10-L15).
- **Simplified client code** with no runtime dependency on Host source [docs/api-gateway.md76-79](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L76-L79).
- **Automatic synchronization** of service API surface and transport protocol [docs/api-gateway.md11-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L11-L16).

## 5.2.2 Decorators for Host Service Annotation: `@Remote` and `@RemoteScope`

Typert leverages the Cordis plugin system and TypeScript decorators to mark Host-side service classes and methods as remotely accessible [docs/api-gateway.md9-15](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L9-L15) [.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md17-22](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md?plain=1#L17-L22).

### `@Remote`

- Applied at the **method** level [docs/api-gateway.md9-11](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L9-L11).
- Indicates that a Host method is accessible remotely [docs/api-gateway.md9-11](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L9-L11).
- Supports both unary RPC and streaming RPC via `Iterable` or `AsyncIterable` return types [packages/api/gateway/README.md35-36](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/api/gateway/README.md?plain=1#L35-L36).
- Captures metadata such as remote method name, parameter types, and codec schemas [docs/api-gateway.md29-34](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L29-L34).

### `@RemoteScope`

- Applied at the **class** or **method** level [docs/api-gateway.md13-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L13-L16).
- Specifies a named contextual resolution scope for the service receiver [docs/api-gateway.md13-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L13-L16).
- Resolves identities through `ctx.typert.contexts` before obtaining the service and invoking the method [docs/api-gateway.md13-16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L13-L16).

## 5.2.3 `TypertRemoteService`: The Runtime Remote Service Host Facade

`TypertRemoteService` is a specialized Cordis service base class that standardizes remote service binding [docs/api-gateway.md15-17](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L15-L17):

- Binds service implementation keys and default Remote namespaces [docs/api-gateway.md15-17](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L15-L17).
- Supports alternative base class inheritance via `bindTypertRemote(this, serviceKey)` [docs/api-gateway.md15-17](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L15-L17).
- Integrates with `TypertGatewayService` (`ctx.typertGateway`) for parameter decoding, lookup resolution, and method invocation [packages/api/gateway/README.md27-32](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/api/gateway/README.md?plain=1#L27-L32).

## 5.2.4 Build Pipeline: Analysis and Emission of RPC Contracts

The Typert build pipeline extracts metadata from the Host `ts.Program` and emits platform-neutral contracts [docs/api-gateway.zh.md95-102](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.zh.md?plain=1#L95-L102) [.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md17-26](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/.agents/notes/implemented/architecture/2026-08-02-typert-remote-method-calls.md?plain=1#L17-L26):

- **Analyzer**: Scans source files for classes and methods decorated with `@Remote` and `@RemoteScope`, building an in-memory model of `InvocationDescriptor` structures [docs/api-gateway.md85-88](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.md?plain=1#L85-L88).
- **Emitter**: Generates static TypeScript declaration files (`.d.ts`), source maps (`.d.ts.map`), and runtime JavaScript files (`.js`) under business package `lib/` paths for consumption by `api/remotes` [docs/api-gateway.zh.md103-112](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/api-gateway.zh.md?plain=1#L103-L112).
