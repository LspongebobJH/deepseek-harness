## Directory Layout & Workspaces

## Package Families & Capability Groups

Packages under `packages/` are partitioned into capability groups (`packages/<group>/<pkg>`) [AGENTS.md15](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/AGENTS.md?plain=1#L15-L15) Each family owns a specific domain, adhering to the Service Definition / Service Provider / Consumer separation pattern [packages/README.md12-80](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L12-L80)

### 1. Core Spine & Execution Loop (`packages/core/`, `packages/agent/`)

- **`dsh-core` / `dsh-agent`**: Establishes the agent service interface, session bindings, and prompt compilation spine [packages/README.md31](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L31-L31)
- **`dsh-agent-loop`**: Implements `ReactLoopAgent`, handling step state machines, inbox ingestion, and publication transactions [AGENTS.md16](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/AGENTS.md?plain=1#L16-L16)
- **`dsh-tools`**: The central tool registry managing pre/execute/post execution waterfalls.

### 2. LLM & Inference Family (`packages/llm/`)

- **`dsh-llm`**: Defines the `LlmRuntime` service definition and abstract streaming protocol [packages/README.md38](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L38-L38)
- **`dsh-llm-deepseek` / `dsh-llm-pi-ai`**: Concrete provider adapters registering against the LLM capability seam [packages/README.md38](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L38-L38)

### 3. Execution Environments & Sandboxing (`packages/shell/`, `packages/fs/`, `packages/sandbox/`)

- **`dsh-fs` / `dsh-fs-local`**: Filesystem service definition and local POSIX implementation [packages/README.md45](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L45-L45)
- **`dsh-shell` / `dsh-subprocess`**: Bash executor seams, local process-tree providers, and persistent PTY sessions [packages/README.md40-42](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L40-L42)
- **`dsh-sandbox`**: Process-confinement seam supporting Landlock (`native/`), bubblewrap (`bwrap`), and Windows restricted tokens [packages/README.md44](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L44-L44)

### 4. Durable Storage & Retrieval (`packages/session/`, `packages/session-query/`)

- **`dsh-session`**: Append-only `SessionEvent` log persistence backends (JSONL, SQLite) [packages/README.md65](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L65-L65)
- **`dsh-session-query`**: Logical corpus retrieval, lineage traversal, and SQLite full-text search [packages/README.md66](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L66-L66)

### 5. API Gateway & Client Runtime (`packages/api/`, `packages/typert/`, `packages/client/`)

- **`dsh-api`**: Remote BFF assembly and HTTP/SSE gateway [packages/README.md32](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L32-L32)
- **`dsh-typert`**: Type graph generator that compiles TypeScript remote service contracts (`api/remotes`) [packages/README.md33](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L33-L33)
- **`dsh-client-*`**: Browser-side plugin modules, slot renderer, and state stores [packages/README.md76](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L76-L76)

## Rules for Adding New Packages & Workspace Constraints

Adding or modifying packages in the monorepo requires strict adherence to validation scripts, naming conventions, and dependency rules [packages/AGENTS.md1-28](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/AGENTS.md?plain=1#L1-L28) [scripts/check-workspace-constraints.ts1-553](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/scripts/check-workspace-constraints.ts#L1-L553)

### 1. Naming & Manifest Conventions

- **Scope & Prefix**: Every npm package under `packages/` must be named `@deepseek-ai/dsh-<name>` and reside in its designated capability group [packages/README.md12](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L12-L12)
- **Cordis Peer Dependency**: `@deepseek-ai/cordis` must be declared as a `peerDependency` and `devDependency` in every harness package manifest (`package.json`) [AGENTS.md104](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/AGENTS.md?plain=1#L104-L104)
- **Module Type**: Packages must target ESM with `"type": "module"` [scripts/check-workspace-constraints.ts80](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/scripts/check-workspace-constraints.ts#L80-L80)

### 2. Dependency Invariants

- **Service Definition Isolation**: Extension plugins must depend solely on **Service Definitions**, never on concrete providers [packages/README.md95](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L95-L95) Concrete providers are injected via profile composition (`cordis.yml`) [packages/README.md95](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/README.md?plain=1#L95-L95)
- **Context Proxy Safety**: Optional services must be accessed via strict `ctx.get(name)` calls rather than property proxies (`ctx.<name>`), avoiding topology-sensitive service lookup failures [packages/AGENTS.md6](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/AGENTS.md?plain=1#L6-L6)

### 3. Quality Gates & Invariant Companions

- **Invariant Check**: Packages that publish diverging runtime observations must provide an `./invariant` companion module [packages/AGENTS.md19](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/AGENTS.md?plain=1#L19-L19)
- **HMR Safety**: Every registry contribution must pass an HMR-safety test that disposes the contributing fiber and asserts complete cleanup [docs/testing.md9](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/testing.md?plain=1#L9-L9)
- **Type Equivalence**: Public types must remain synchronized with generated subsystem catalogs verified by `verify-type-equiv` [docs/AGENTS.md41-42](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/AGENTS.md?plain=1#L41-L42)
