## Overview of ReactLoopAgent

The `ReactLoopAgent` class serves as the default concrete agent driver in `dsh`, fulfilling the public `Agent` contract [packages/core/agent-loop/src/agent.ts72](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L72-L72) It handles the complete lifecycle of an execution session from message intake through model requests and tool execution loops [packages/core/agent-loop/src/agent.ts72-112](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L72-L112)

Key architectural characteristics include:

- Consumes incoming user messages via an append-only `ReactLoopInbox` instance backed by session projections [packages/core/agent-loop/src/agent.ts35](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L35-L35) [packages/core/agent-loop/src/agent.ts106](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L106-L106)
- Drives conversation progress across discrete `turn` and `step` boundaries [docs/architecture.zh.md86-107](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/architecture.zh.md?plain=1#L86-L107)
- Leverages Cordis event taxonomies for plugin-based observation and extension [docs/architecture.md11-14](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/architecture.md?plain=1#L11-L14)
- Implements cooperative cancellation using `AbortController` signals [packages/core/agent-loop/src/agent.ts149-155](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L149-L155)
- Provides a dedicated maintenance mode (`runMaintenance()`) for background operations [packages/core/agent-loop/src/agent.ts157-174](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L157-L174)

## Turn/Step State Machine

### Concepts

- **Turn:** A logical conversation segment spanning zero or more steps. A turn opens when the first input message is claimed and closes when no further work remains owed [docs/architecture.zh.md86-107](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/architecture.zh.md?plain=1#L86-L107)
- **Step:** A single request-response cycle with the LLM together with any associated tool calls and results [docs/architecture.zh.md86-107](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/docs/architecture.zh.md?plain=1#L86-L107)

### Internal State Phases

The agent tracks its lifecycle via a private `phase` variable conforming to a discriminated union [packages/core/agent-loop/src/agent.ts41-50](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L41-L50) [packages/core/agent-loop/src/agent.ts74](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L74-L74):

- `idle`: Waiting for input or maintenance work; not actively driving [packages/core/agent-loop/src/agent.ts42](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L42-L42)
- `maintenance`: Executing an exclusive background job (`runMaintenance()`) that temporarily blocks active work. Wakeups received during this phase are latched [packages/core/agent-loop/src/agent.ts43-48](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L43-L48) [packages/core/agent-loop/src/agent.ts157-174](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L157-L174)
- `running`: Actively executing a conversation turn or step [packages/core/agent-loop/src/agent.ts49](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L49-L49)

## Cancellation & Maintenance Mechanics

### Cooperative Cancellation via `cancel()`

The agent supports task cancellation through `cancel(cause, options)` [packages/core/agent-loop/src/agent.ts149-155](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L149-L155):

- Default behavior clears the inbox and aborts the active `AbortController`, terminating ongoing LLM streams and tool execution steps [packages/core/agent-loop/src/agent.ts150-154](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L150-L154)
- Passing `keepInbox: true` preserves queued inbox items so they can be processed in subsequent turns after the active turn reaches quiescence [packages/core/agent-loop/tests/cancel.spec.ts105-130](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/tests/cancel.spec.ts#L105-L130)

### Maintenance Mode via `runMaintenance()`

- `runMaintenance()` allows running exclusive background tasks while the agent is otherwise idle [packages/core/agent-loop/src/agent.ts157-174](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L157-L174)
- During the `maintenance` phase, incoming wake requests are latched rather than spawning concurrent turns [packages/core/agent-loop/src/agent.ts47](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L47-L47) [packages/core/agent-loop/src/agent.ts164](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L164-L164) Once the task settles, the driver transitions back to `idle` and processes the latched wakeups [packages/core/agent-loop/src/agent.ts171-173](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L171-L173)

## Epoch Headers & Publication Transaction Pattern

### Epoch Headers: Anchoring Model Requests

Model requests are preceded by an `EpochHeader` that records effective LLM configuration and runtime parameters [packages/core/agent-loop/src/agent.ts63-69](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L63-L69) These headers are written to the session log as durable events to guarantee:

- Exact reproduction of adapter-configured defaults during session replaying [packages/core/agent-loop/README.md92-94](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/README.md?plain=1#L92-L94)
- Configuration consistency across retries and turns [packages/core/agent-loop/README.md92-94](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/README.md?plain=1#L92-L94)
- Removal of transient adapter defaults via `requestProposal()` before subsequent plugin proposals [packages/core/agent-loop/src/agent.ts62-69](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L62-L69)

### Publication Transaction for Agent Lifecycles

Agent creation and registry publication follow an atomic transaction pattern [packages/core/agent-loop/src/index.ts96-146](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/index.ts#L96-L146):

1. **Preparation Phase:** Construct the session and `ReactLoopAgent` instance without global publication [packages/core/agent-loop/src/agent.ts96-112](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/agent.ts#L96-L112)
2. **Setup Phase:** Execute agent-scoped initialization callbacks (e.g., `setup(agentCtx, agent)`) to configure tools and prompt sections [packages/core/preset-agent-presets/tests/mount.spec.ts64-68](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/preset-agent-presets/tests/mount.spec.ts#L64-L68)
3. **Publication Phase:** Register the session into `ctx.sessions` and the agent into `ctx.agents`. In case of collision, roll back the transaction [packages/core/agent-loop/src/index.ts96-146](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/src/index.ts#L96-L146)
4. **Teardown Phase:** Upon disposal, halt the agent loop, unregister from registries, unwind the scope, and reclaim resources [packages/core/agent-loop/README.md61](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/core/agent-loop/README.md?plain=1#L61-L61)
