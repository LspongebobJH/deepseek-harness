The DeepSeek Harness (`dsh`) Web UI is a modular, plugin-based React application built on the **Cordis** framework. It provides a rich, extensible environment for interacting with AI agents, managing code workspaces, and inspecting execution trajectories. The architecture emphasizes a strict separation between browser-side presentation logic and host-side execution, bridged by a type-safe RPC layer. Theme-facing colors and styles rely on `--dsw-*` design tokens [packages/client/ui-primitives/README.md12](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/client/ui-primitives/README.md?plain=1#L12-L12)

## Plugin Architecture & Slot System

The browser client is composed of independent packages that declare dependencies and register components into named slots via `ctx.slots.register()` and `ctx.slots.inject()` [packages/extensions/cordis-client-runner/src/client/slot-catalog.ts67-75](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/extensions/cordis-client-runner/src/client/slot-catalog.ts#L67-L75) Dynamic packages contribute UI elements without modifying core shell code, using compile-time contracts specified in slot catalogs [packages/extensions/cordis-client-runner/src/client/slot-catalog.ts1-75](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/extensions/cordis-client-runner/src/client/slot-catalog.ts#L1-L75)

Dedicated feature packages like `@deepseek-ai/dsh-client-ui-conversation` orchestrate the conversation view layout, message streaming, and composition inputs [packages/client/ui-conversation/package.json28-42](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/client/ui-conversation/package.json#L28-L42)

## Key UI Subdomains & Child Pages

### 1. Conversation UI & Chat View

The `ui-conversation` package provides the core conversation skeleton (`ConversationRoot`), Chat views, input states, and the `InputBar` component backed by a Lexical editor. It handles streaming, steering, queue management, and temporary composer takeovers [packages/client/ui-conversation/package.json3-42](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/client/ui-conversation/package.json#L3-L42)  
For details, see [Conversation UI & Chat View](./6.1-conversation-ui-and-chat-view.md).

### 2. Workspace Browser & Sidebar

The `ui-workspace` package handles workspace selection, the session tree hierarchy, and directory pickers (`WorkspaceBrowser`, `WorkspacePicker`). It integrates with `ui-sidebar` for sidebar state management and `ui-layout` for AppFrame column partitioning.  
For details, see [Workspace Browser & Sidebar](./6.2-workspace-browser-and-sidebar.md).

### 3. UI Primitives, Trajectory & Tool Views

Shared UI primitives (`ui-primitives`) supply Markdown renderers, code blocks, file-type icons, and terminal blocks without importing Cordis runtimes [packages/client/ui-primitives/README.md12](https://github.com/deepseek-ai/deepseek-harness/blob/ddefc45f/packages/client/ui-primitives/README.md?plain=1#L12-L12) The `ui-tool` package renders tool calls, deliverables, and present cards within the trajectory inspection ledger.  
For details, see [UI Primitives, Trajectory & Tool Views](./6.3-ui-primitives-trajectory-and-tool-views.md).

### 4. Settings, Agent Presets & Onboarding

User-facing configuration is managed through the settings UI (`ui-settings`), which includes model selection, plugin toggles, general preferences, agent preset authoring, and the onboarding flow.  
For details, see [Settings, Agent Presets & Onboarding](./6.4-settings-agent-presets-and-onboarding.md).

### 5. Desktop App & Web Shell Packaging

The Electron desktop application (`apps/desktop`, `desktop-host`) manages host process lifecycles, project management, packaging, signing, and auto-updates. The `apps/web` package provides the Vite shell and boot graph.  
For details, see [Desktop App & Web Shell Packaging](./6.5-desktop-app-and-web-shell-packaging.md).
